# LONG_TERM_MEMORY

- Long-term memory includes dated notes in `memory/`. `.learnings/` contains ephemeral reflection/audit logs for self-evolution decisions, not durable task memory; recorded lessons should be promoted into enabled agent updates or treated as ignorable/discardable audit residue.
- Use memory retrieval tools to fetch relevant context before relying on remembered details.
- Treat retrieved memories as evidence to inspect and interpret, not as unquestionable truth.
- If the active evolution surface is `long_term_memory`, policy changes about retrieval, ranking, and use of memory belong here.
- Use this file for high-level policy about how retrieved memories should influence reasoning and task execution.
