# LONG_TERM_MEMORY_SUMMARIZATION

- This file defines what should be promoted into the always-in-context `MEMORY.md`.
- `MEMORY.md` should remain compact and selective.
- Prefer stable facts, persistent preferences, active commitments, durable procedures, and unresolved follow-ups.
- Do not copy bulky raw notes or transcript-like dumps into `MEMORY.md`.
- If the active evolution surface is `long_term_memory`, prompt-level changes to what gets summarized into `MEMORY.md` belong here.
